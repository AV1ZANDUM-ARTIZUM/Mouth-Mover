# Mouth Mover

A simple browser-based mouth mover project.

## Current status

This repository currently contains the packaged starter and v3 project archives. The next step is to unpack the working web app into normal source files so GitHub Pages can serve it directly.

## Files

- `mouth-mover-starter new.zip` — starter build
- `mouth-mover-v3.zip` — v3 build

## Running the project

The ZIP archives contain the current project builds. For GitHub Pages, the app should be placed in the repository root with an `index.html` entry point.
